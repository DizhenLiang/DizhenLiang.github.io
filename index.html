The Facility / 整套设施

不是一套代码，是一台机器。

Apex-Agent 把「长任务」跑成「产品」：任务定义、隔离执行、独立评测、数据回流，四个环节咬合成一个可自我改进的飞轮。

01 / 飞轮

任务定义 → 隔离工作区 → 智能体执行 → 独立评测 → 数据回流

五个环节咬合，每一轮都把「失败」变成下一轮的「数据」。没有一次性脚本，只有持续变强的机器。

76 任务 × 38 模块
02 / 双沙箱

bubblewrap 执行沙箱 + Harbor 评测沙箱

执行与评测物理隔离：被评测的代码跑在 Harbor 里，评测器跑在沙箱外——既不可泄漏数据，也不能被改答案。

执行 / 评测 双平面
03 / 自愈与巡检

重试 · watchdog · 巡检 · 熔断

失败自动重试，卡死由 watchdog 回收；1,648 行巡检代码 + 1,745 个测试把「静默错误」提前暴露；连续 5 次失败触发熔断。

1,131 次异常上报 · 36 次预置故障验证
04 / 可观测

三平面指标 + 全量日志 + 异常上报

Pushgateway / Prometheus / Langfuse 三平面，40/40 日志 + 40/40 异常上报；每一条轨迹都能回放到「哪一步、哪一行」。

可回放 · 可定位 · 可审计
